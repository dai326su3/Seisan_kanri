# 生産管理 タブレット入力(包装指図書)

紙の包装指図書をタブレット入力に置きかえ、記録をGoogleスプレッドシートにためるための画面です。

| ファイル | 中身 |
|---|---|
| `index.html` | タブレットの入力画面(GitHub Pages で公開) |
| `gas/Code.gs` | Googleスプレッドシート側のプログラム(Apps Script)。控えとして置いています |

記録や商品マスタはGoogleスプレッドシートの中にあり、このリポジトリには入っていません。

## 1. GitHub Pages をオンにする(最初に1回)
1. このリポジトリの **Settings → Pages** を開く
2. Source: **Deploy from a branch**、Branch: **main** / **(root)** を選んで Save
3. 1〜2分後に `https://dai326su3.github.io/Seisan_kanri/` で画面が開く

## 2. スプレッドシートとApps Script(10分)
1. Googleドライブで新しいスプレッドシートを作る(名前の例: 包装指図書_記録)
2. 「拡張機能 → Apps Script」を開き、`gas/Code.gs` の中身を丸ごと貼り付けて保存
3. 関数選びで `setup` を選んで「実行」→ 権限の確認が出たら許可
   → M_商品・M_担当・オーダー登録・包装実績・集計_日別 の5シートができる
4. 「デプロイ → 新しいデプロイ → 種類: ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - 表示されたURL(`https://script.google.com/macros/s/…/exec`)を控える

## 3. 画面とスプレッドシートをつなぐ
`index.html` の `const GAS_URL = "PASTE_YOUR_WEB_APP_URL_HERE";` を、手順2-4のURLに書き換える。

## 4. マスタを入れる
- **M_商品**: 商品マスタのたたき台(プロジェクトの `M_商品_初期データ.csv`)を「ファイル → インポート → 現在のシートに置換」で読み込み、包装ライン・箱入数・消費期限日数・集計先商品ID・集計先生地IDを埋める
- **M_担当**: 担当者の名前と包装ライン(空欄なら全ライン)

## 5. タブレット
- 各タブレットで `https://dai326su3.github.io/Seisan_kanri/?device=包装1` のように端末名をつけて開き、「ホーム画面に追加」
- 端末名は一度開けば記憶されます(包装実績の「端末」列に入る)

## 毎日の運用
- **前日(事務所)**: オーダー登録シートに 日付・商品ID・オーダー数 を入れる
- **当日(包装)**: ラインと担当を選び、品目をタップして出来高などを入れ「確定して送る」
- **確認(事務所)**: 集計_日別 のB1に日付を入れると、品目別・生地別の合計が出る

## しくみの補足
- 包装実績は1行=1記録。直したいときはタブレットで入れ直すと、前の行が「取消」になり新しい行が増える
- 電波が切れても記録は端末に残り、つながったら自動で送る(「もう一度送る」ボタンでも送れる)
- 朝5時までは前日の製造日を表示(夜勤の包装用)。◀▶で日付を変えられる
